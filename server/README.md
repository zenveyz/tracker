# Kosmic Премиум — подключение оплаты

Деньги идут на твой аккаунт в платёжном сервисе, а оттуда выводятся на твою карту или счёт.
Kosmic и GitHub к деньгам и данным карт доступа не имеют.

## 1. Платёжный сервис (пример: Lemon Squeezy)
1. Зарегистрируйся на lemonsqueezy.com. Укажи страну и способ вывода денег (проверь, что твоя страна поддерживается).
2. Создай товар **Kosmic Премиум** → тип **Single payment** (разовая оплата) → цена 10 $.
3. В настройках товара включи **License keys**: тогда покупатель получит ключ на почту.
4. Скопируй ссылку на оплату (кнопка **Share**) — это `checkoutUrl`.
5. Запиши **Store ID** (Settings → Stores) и **Product ID** (в адресе страницы товара).

## 2. Сервер проверки ключей (Cloudflare Worker, бесплатно)
1. Зарегистрируйся на dash.cloudflare.com → **Workers & Pages** → **Create** → **Worker**.
2. Нажми **Edit code**, вставь содержимое `premium-worker.js` и нажми **Deploy**.
3. **Settings → Variables**: добавь `STORE_ID`, `PRODUCT_ID`, `ALLOWED_ORIGIN` = `https://zenveyz.github.io`.
4. Адрес Worker (вида `https://kosmic-premium.ИМЯ.workers.dev`) — это `verifyUrl`.

## 3. Приложение
В `js/premium.js` заполни блок `CONFIG`: цену, `checkoutUrl` и `verifyUrl`.
Потом `git add -A`, `git commit -m "Подключил оплату"`, `git push`.

## Проверка без оплаты
На `localhost` ключ `TEST-PREMIUM` включает Премиум (на опубликованном сайте он не работает).

## Что важно знать
- Сайт работает в браузере, поэтому опытный пользователь может обойти проверку через консоль.
  Для небольшого приложения это нормально: ключ всё равно перепроверяется сервером раз в сутки.
- Премиум покупается один раз навсегда. Если ты вернёшь деньги и отключишь ключ в Lemon Squeezy — в течение суток
  (без интернета — до 7 дней) Премиум выключится. Уже созданные свои упражнения останутся.

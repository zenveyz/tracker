# Kosmic — тренировки, еда, цели, привычки

Сайт-приложение (PWA). Работает на телефоне и на компьютере, без сервера: все данные хранятся в браузере на устройстве.

## Как открыть на компьютере
Дважды кликни **start.bat**: откроется http://localhost:5173 (нужен установленный Python).
Если просто открыть `index.html` двойным кликом, сайт не заработает: браузер не запускает модули с диска.

## Разделы
- **Главная** — анимированная гора: стикмен поднимается к вершине по мере выполнения дел за день (тренировка, вода, еда, привычки, сон). Небо меняется по времени суток.
- **Тренировки**
  - **Тело** — 3D-модель с разметкой мышц: крутить пальцем, щипок — зум, двумя пальцами — двигать. Нажми на мышцу (или выбери в списке) → упражнения с анимацией техники → нажатие на упражнение подсвечивает основные и вспомогательные мышцы. Кнопка слоёв переключает белый и цветной стиль.
  - **Мои** — выбранные упражнения.
  - **Неделя** — план по дням (подходы, повторы, вес), отметки выполнения, итог недели.
  - **История** — календарь за месяц или год (зелёный — тренировка, красный — пропуск, серый — отдых) и 3D-тело: мышцы, которые ты тренировал больше всего за период, насыщенно-красные, почти нетронутые — белые.
- **Сон** — запись «лёг/встал», качество, статистика, календарь за месяц/год (цвет зависит от длительности сна относительно цели).
- **Еда** — калории, БЖУ, вода и напитки, календарь за месяц/год (насколько день близок к цели по калориям).
- **Цели** — разовые (свайп вправо = выполнено) и с прогрессом.
- **Привычки** — каждый день, количество, таймер «сколько прошло» и секундомер; календарь за месяц/год (какая доля привычек выполнена).
- **Настройки** — имя, тема, сохранение и загрузка резервной копии.

## Где хранятся данные
- Только в браузере (localStorage) на этом устройстве. На сервер ничего не отправляется.
- Телефон и компьютер не синхронизируются. Перенос — через **Настройки → Резервная копия**: «Сохранить» на одном устройстве, «Загрузить» на другом.
- Данные привязаны к адресу сайта: то, что введено на `localhost`, не появится на опубликованном сайте само — перенеси резервной копией.
- На iPhone установи сайт на экран «Домой» (Safari → «Поделиться» → «На экран Домой»): так Safari не удалит данные, если долго не заходить. Приложение и само просит браузер хранить данные постоянно.

## Как опубликовать на GitHub Pages
1. Создай на github.com новый **публичный** репозиторий (например, `kosmic`), без README.
2. В папке проекта выполни (подставь свой логин):
   ```
   git remote add origin https://github.com/ЛОГИН/kosmic.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ЛОГИН.github.io/kosmic/`.

После изменений: `git add -A`, `git commit -m "что изменил"`, `git push` — сайт обновится сам. Если открыт старый вариант, перезагрузи страницу.

## Структура
- `index.html`, `css/styles.css`, `manifest.webmanifest`, `sw.js` (офлайн-режим и установка)
- `js/app.js` — навигация, `js/store.js` — хранилище
- `js/anatomy3d.js` — 3D-тело (Three.js с CDN jsDelivr, кешируется для офлайна)
- `models/` — модель тела с разметкой мышц
- `js/heatmap.js`, `js/stats.js` — календари за месяц/год
- `js/figure.js` — анимации упражнений, `js/hero.js` — сцена «Гора»
- `js/data/exercises.js` — база упражнений, `js/views/*` — разделы
- `js/body.js`, `js/bodyview.js` — 2D-схема (запасной вариант, если 3D недоступно)
- `mockup/` — макет и сборка 3D-модели (`node mockup/tools/build2.mjs 0.42 0.9 10`; нужен исходный `male_body.glb` в `mockup/model/`, он не хранится в репозитории)
- `tools/` — страницы для проверки иллюстраций и 3D
